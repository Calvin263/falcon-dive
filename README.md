# Falcon Dive

Fly, hunt, and upgrade your falcon in this browser game.

## Play locally

From the project folder, run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

Then open http://localhost:8081/ in your browser and follow the on-screen instructions.

Starting another Falcon Dive server from this checkout on ports 8080-8089 stops the previous one, including the browser test server. Unrelated services are left alone.
